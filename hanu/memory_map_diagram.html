📝 Key Notes

  • ITCM & DTCM: Fast 1-cycle access via FPGA Block RAM. Ideal for real-time operations and interrupt handlers.
  • External DDR3: 256 MiB capacity with variable latency (10-40 cycles via MIG controller). Use for bulk data storage.
  • CLINT: Contains machine timer (mtime) and software interrupt (msip) registers. Runs at fixed 10 MHz reference clock.
  • PLIC: Platform-Level Interrupt Controller aggregates peripheral interrupts.
  • Peripherals: GPIO, UART0, SPI0, I2C0 are memory-mapped at 0xF000_xxxx. Each occupies 4 KiB address space.
  • Memory Map Lock: Fixed in RTL and must match linker script (link.ld). Changes require RTL regeneration.

📖 Memory Region Details

⚡ ITCM & DTCM (Fast Memory)

Single-cycle access latency makes these regions ideal for real-time code and interrupt handlers. TCMs are implemented using FPGA Block RAM for predictable performance. ITCM holds frequently-executed code; DTCM holds stack and critical data. Total: 64 KiB.

💾 External DDR3 (Bulk Storage)

256 MiB capacity with 10-40 cycle variable latency via Xilinx MIG (Memory Interface Generator) controller. Suitable for application data, buffers, and non-critical code. Pipeline stalls on DDR3 accesses to maintain data consistency.

⏱️ CLINT (Interrupt Timing)

Contains machine software interrupt (msip) at 0xE000_0000 and machine timer (mtime/mtimecmp) at 0xE000_BFF8. Timer increments at fixed 10 MHz reference clock (100 ns per tick). Essential for RTOS tick generation. Priority: MSI > MTI.

🔌 PLIC (Interrupt Aggregation)

Platform-Level Interrupt Controller aggregates peripheral interrupts from GPIO, UART, SPI, I2C, and external sources. Supports interrupt prioritization and enables/disables per-interrupt. Highest priority: MEI (Machine External Interrupt).

🎮 Peripherals (GPIO, UART, SPI, I2C)

Memory-mapped peripheral region starting at 0xF000_0000. Each peripheral occupies 4 KiB. GPIO for digital I/O, UART for serial communication, SPI for sensor interfaces, I2C for standard two-wire protocols. All accessed via AXI-Lite bus.

⚠️ Reserved & Boot ROM

Boot ROM (16 KiB @ 0x0000_0000) contains first-stage bootloader and initialization code. All other addresses above 0xF000_4000 are reserved and trigger access fault exceptions (mcause = 0x05/0x07).
