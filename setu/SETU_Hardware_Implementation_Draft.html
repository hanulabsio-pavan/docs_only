1. System Architecture Overview

The SETU board operates from 230VAC mains and strictly separates three functional domains for safety and performance.

Domain Voltage Isolation Risk Level
HV Power Stage 230VAC / 325V DC bus HV side Lethal
Load Switching Stage 230VAC (relay contacts) HV side Lethal
Logic Stage 3.3V / 5V DC LV side (isolated) Safe

HV DOMAIN (230VAC)

  • Surge → Fuse → EMI Filter
  • Rectifier → Bulk Cap
  • Flyback Transformer Primary
  • Relay Contacts (COM/NO/NC)
║

LV DOMAIN (3.3V / 5V)

  • ESP32-S3 MCU
  • Touch IC (CAP1296)
  • LED Drivers / WiFi Antenna
  • Relay Coil Driver (Isolated)

2. Power Stage Architecture

Stage 1 — Input Protection & Filtering

Designed for Indian mains conditions (spikes, noise, and instability).

Ref Function Critical Spec (India)
F1Slow-blow fuse500mA/250VAC (PSU rail only)
RV1MOV275VAC continuous, ≥80J surge energy
F2Load fuse10A/250VAC (One per gang)
C1X2 Capacitor100nF/275VAC X2-rated
India-Specific Requirement: MOV must be rated 275VAC (not 250VAC). Indian grid voltage frequently sustains 270V+; a 250V component will degrade rapidly.

Stage 3 — Isolated Flyback Converter

Galvanic isolation is non-negotiable for a premium touch-based product.

  • Phase 1: Using HLK-PM05 encapsulated module for rapid prototyping.
  • Phase 3: Custom TNY268PN based design for cost and footprint optimization.

3. Logic Stage Architecture

3.1 Main MCU — ESP32-S3

Selected for native AI acceleration (Voice) and superior connectivity.

SelectionESP32-S3-WROOM-1-N8R8
Memory8MB Flash + 8MB PSRAM
FeaturesWiFi, BLE 5.0, Vector instructions for TFLite

3.2 Touch Controller — CAP1296

Hardware-level touch sensing with superior EMI rejection compared to MCU-based sensing.

SelectionCAP1296-1-SN
InterfaceI2C (up to 400kHz)
Key FeatureActive shielding output to minimize false triggers in HV environments

8. Critical Design Rules Checklist

  • HV Protection: Fuse F1 is the absolute first element after J1 input.
  • Thermal: Bulk cap C3 rated for 450V (Standard 400V is insufficient for India).
  • Isolation: Physical slot routed in PCB between HV and LV zones.
  • RF: 15mm copper-free keepout zone below ESP32 antenna.
  • Touch: 1MΩ series resistors placed immediately at IC pins.
