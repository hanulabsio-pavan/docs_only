1. Quick Overview

This document is the single source of truth for how the SETU repository is organized. Golden Rule: Distinguish clearly between Design and Production files.

Type Definition Examples
Design Files Source of truth. Files you edit. KiCad .kicad_sch, C source .c
Production Files Exported FROM design. Never edit directly. Gerbers, BOM CSV, Firmware .bin

3. Hardware Section Detail

3.1 Schematics

Naming: SETU_SCH_v{major}.{minor}.kicad_sch

  • Store KiCad source and custom libraries.
  • Do NOT store PDFs or Gerbers here.

3.2 PCB Layout Constraints

Board Outline140mm × 100mm
Stackup4-layer (Signal / GND / PWR / Signal)
HV Clearance4mm creepage / 2.5mm clearance

4. Firmware Section Detail

Structure follows a modular approach for ESP-IDF:

ComponentDescription
main/Entry point and task initialization
drivers/Touch (CAP1296), Relay, and LED drivers
middleware/WiFi, OTA, and Voice Engines
