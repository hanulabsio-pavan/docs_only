Terminates CHI SN-F link. Manages FIFOs and credits for all 4 CHI channels (RX REQ, RX DAT, TX RSP, TX DAT).

🔵 Address Processing Engine (APE)

▾
APE
Address Processing
PA → {rank, bg, bank, row, col}

1) Hole removal (MMIO carve-out), 2) XOR hash (programmable masks), 3) Bit-select address field mapping.

HASH_MASK_BG0[43:0] HASH_MASK_BG1[43:0] HASH_MASK_BANK0 HASH_MASK_RANK
Tiny

XOR trees: ~50 gates. Mux field selectors: ~200 gates. Fully combinatorial.

🟣 Refresh Engine & Command Arbitration

▾
RME
Refresh & Maintenance Engine
DDR5 periodic maintenance

Init FSM (power-on sequence), Refresh FSM (tREFI periodic), Self-Refresh FSM, Power-Down FSM, ZQ Calibration FSM.

tREFI = 3.9 µs (1x) / 1.95 µs (2x at >85°C). Max deferred: 8 (JEDEC allows 9). REFab default; REFpb optional via register.

~300 LUTs
CAL
Command Arbitration Layer
Priority multiplexer
  1. Initialization (absolute)
  2. Deferred refresh (limit reached)
  3. ZQ Calibration
  4. Normal Refresh
  5. Power-Down Exit
  6. User HiQoS Reads
  7. User HiQoS Writes
  8. User LoQoS
  9. Power-Down Entry (idle only)

🟢 DFI Translation & Response Path

▾
DTL
DFI Translation Layer
NMI → DFI 5.0 signals
dfi_address[13:0] dfi_act_n dfi_rddata_en dfi_wrdata[255:0] dfi_wrdata_mask dfi_lp_ctrl

ACT uses 2-cycle command (ACT1+ACT2). DTL sequences transparently. BL16 encoding for RD/WR. ZQ two-step ZQCAL START/LATCH.

~500 LUTs
RSP
Response Path
Read data & write completion

5-bit tracker_id shift register, depth = max_RL (~40 cycles). SRL32 on FPGA = negligible area. Reaches output same cycle as dfi_rddata_valid.

Write latency counter (WL + BL/2 + 2 cycles). Issues Comp RSP flit then frees tracker entry.

dfi_rddata_err → RESPERR_DERR in CompData. PHY update stall handled in DTL.

~200 LUTs

⚙️ DDR5 Specific Optimizations

▾
PG
Page Policy
Open vs Closed vs Adaptive

Adaptive open-page default. If ≥ 2 consecutive hits to same row → keep open. Otherwise auto-precharge (closed).

2-bit hit counter per bank × 16 banks = 32 bits total. Negligible.

30–50% bandwidth improvement over closed-page for CPU streaming workloads.

BG
Bank Group Utilization
DDR5 tCCDL vs tCCDS

tCCDS (diff BG): ~4 cycles. tCCDL (same BG): ~8 cycles. Alternating across BGs doubles CAS throughput.

BG bits at low PA positions (PA[6:7]) so sequential cache lines naturally alternate bank groups.

REF
Refresh Strategy
REFab vs REFpb

Simple. Single timer. Correct per JEDEC DDR5. Stalls all banks for tRFC1 (~350–550 ns).

Shorter stall. Only target bank stalled. Enable via REFRESH_MODE register after validation.

Program to 8 (JEDEC allows 9) for margin.

MR
Multi-Rank Support
2 ranks per channel

Rank bit in APE output. Per-rank bank state table (16 states × 2 ranks). Round-robin rank selection in scheduler.

Rank-to-rank switching: tRRDS + ODT switching. CAL enforces via global tRRDS timer.

~2× bank_state_t array size. Still negligible (~64 bytes total).
