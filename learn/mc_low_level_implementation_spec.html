🟠 RQA — Request Queue Array

▾
Structure

Per-BG Queues (×4)

8 entries each × 51 bits = ~51 bytes per queue. LUTRAM on FPGA. Head always visible to scheduler (combinatorial read).

Global Overflow Queue

16 entries × 51 bits. Accepts spill when BG queue full. Drained back to BG queues when space available. LUTRAM.

Admission Policy
// New entry: target BG queue first, overflow if full always_comb begin push_to_bg = push_valid && (bg_level[push_bg] < BG_QUEUE_DEPTH); push_to_ovf = push_valid && !push_to_bg && (ovf_level < OVF_QUEUE_DEPTH); push_ready = push_to_bg || push_to_ovf; end
Age Increment

Every entry's age field is incremented by 1 each cycle it remains in the queue (saturates at 0xFF). Used by scheduler starvation logic.

🟠 SCH — DDR5 Scheduler

▾
Per-Cycle Selection Algorithm
// Round-robin across BGs (rr_bg_ptr advances every cycle regardless of issue) for (int i = 0; i < MC_NUM_BG; i++) begin bg_idx = (rr_bg_ptr + i) % MC_NUM_BG; if (bg_valid[bg_idx]) begin entry = bg_head[bg_idx]; bank_idx = entry.rank*MC_NUM_BG*MC_BANKS_PER_BG + entry.bg*MC_BANKS_PER_BG + entry.bank; bst = bank_st[bank_idx]; if (bst.row_open && bst.open_row == entry.row && bst.tRCD_rem==0 && cas_timing_ok) begin // Row hit → issue RD/WR issue_cmd(entry.cmd == 2'b00 ? NMI_RD : NMI_WR, entry); end else if (!bst.row_open && bst.tRP_rem==0 && faw_ok && tRRD_ok(bg_idx)) begin // Row closed → issue ACT issue_cmd(NMI_ACT, entry); end else if (bst.row_open && bst.open_row != entry.row && bst.tRAS_rem==0) begin // Different row open → issue PRE issue_cmd(NMI_PRE, entry); end break; // only one command per cycle end end

// Shift register of depth tFAW; set bit on ACT, shift each cycle logic [tFAW_MAX-1:0] faw_sreg; always_ff @(posedge clk) begin faw_sreg <= {faw_sreg[tFAW_MAX-2:0], act_issued}; end assign faw_ok = ($countones(faw_sreg[csr.tFAW-1:0]) < 4);

RD + WR Collision Handling

If rd_valid and wr_comp_valid assert in the same cycle: serve read (dat) first, buffer write completion in a 1-entry pending register. Issue Comp on next cycle.
