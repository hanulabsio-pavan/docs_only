4 × 4 Mesh — Node Placement

Mesh Routing Rules

XY Deterministic Routing
1
Route in X direction first
If dst_x > my_x → go EAST; if dst_x < my_x → go WEST.
2
Route in Y direction second
Once X matches, if dst_y > my_y → go NORTH; dst_y < my_y → go SOUTH.
3
Eject to Local port
When both X and Y match destination, deliver to local CHI node.
