Section 03
HN-F — Home Node (Full)

The coherency brain. Contains the snoop filter, transaction tracker, multiple arbiters, and address decoder. Must maintain ordering for all transactions to its address range.

🔍 Snoop Filter CAM
  • Set-associative CAM — content-addressed by physical address
  • Sharer bitmap — one bit per RN-F node in system
  • Aggregated state — worst-case across all sharers
  • PLRU replacement — eviction forces SnpMakeInvalid
  • Hit → targeted SNP; Miss → broadcast all RN-Fs
  • N−1 bits per set for PLRU state
📋 Transaction Tracker SRAM
  • One entry per in-flight txn — HN-F resource limit
  • RetryAck issued when full (AllowRetry=1)
  • PCrdGrant sent when slot frees
  • Ordering point — serialises conflicting addresses
  • State FSM — tracks each txn through protocol steps
  • Stores: TxnID, SrcID, Addr, snoop state, data-pending flag
⚖️ Request Arbiter Logic
  • QoS-weighted round-robin across REQ flits
  • Hazard detection — stall if address conflict in tracker
  • Starvation prevention — QoS escalation timer
  • Credit accounting — per-requester credit pool
  • Ordering preservation — same-address serialisation
🗺️ Address Decoder Logic
  • Maps address → SN-F — programmed at boot
  • Non-coherent range — routes to HN-I instead
  • Interleave logic — stripe across multiple SN-Fs
  • Generates TgtID for ReadNoSnp/WriteNoSnp to SN
⚙️ Protocol Engine FSM
  • Per-txn state machine — 20+ states per protocol flow
  • Snoop dispatch — generates SNP flits from tracker
  • Data forwarding — DCT path management
  • Writeback handling — dirty data → SN-F
  • CMO processing — CleanShared, CleanInvalid
  • CompAck tracking — waits before tracker release
💾 Data Buffer SRAM
  • Temporary hold — dirty data from snoop response
  • DBID issued — to requester for write data alignment
  • Parallel path — forward to CPU + write to SN-F
  • ECC protected — data integrity during transit
Section 04
SN-F — Slave Node (Full)

The simplest coherent node. No caching, no snoops, no coherency logic. Receives ReadNoSnp / WriteNoSnp from HN-F and returns data or acknowledges writes.

🔌 CHI SN Interface
  • REQ channel RX — accepts ReadNoSnp, WriteNoSnp
  • DAT channel TX/RX — data to/from HN-F
  • RSP channel TX — CompAck, DBIDResp
  • No SNP channel — never snooped
📥 Write Buffer
  • Accepts CopyBackWrData from HN-F
  • Coalesces partial writes — BE masking
  • Drain policy — write to DRAM at burst boundary
  • Issues DBIDResp to allocate buffer slot
🏦 Memory Controller
  • DRAM scheduler — row/column arbitration
  • Refresh controller — tREFI/tRFC management
  • Data path ECC — SECDED per burst
  • Timing engine — DDR/LPDDR protocol
⚡ Read Buffer
  • Prefetch queue — anticipate sequential reads
  • DataID splitting — 64B → 2×32B DAT flits
  • CCID ordering — critical chunk first
  • Returns CompData to HN-F
Section 05
Mesh Router — Internal Sub-Units

Each mesh crosspoint routes flits from any input port to any output port. Deadlock-free routing via dimension-ordered routing (X→Y). No flit modification — purely forwarding.

Section 06
Link Layer — Layer 1 Sub-Units

The Link Layer sits between the Protocol Layer and physical wires. Manages flit-level flow control via L-credits. Independent per virtual channel. Prevents buffer overflow without global stalls.

Sub-UnitFunctionPer VC?Credit Width
TX Credit Counter Tracks how many flits sender can transmit. Decrements on send. Yes log₂(depth)
RX Credit Return Generates LCrdReturn flit after consuming received flit. Yes —
Input Buffer FIFO per VC. Absorbs burst. Depth determines max in-flight. Yes 2–8 flits
Flit Encoder Serialise fields → parallel wire width. Add parity/ECC. No (shared) —
Flit Decoder Deserialise received bits → flit fields. Check ECC. No (shared) —
Clock Domain Cross FIFO for crossing from local to link clock domain. Yes —
Power Controller Clock gate VC when empty. Link power-down when all idle. Yes —
Credit Rule: Sender may transmit only if credit count > 0. Each transmitted flit decrements credit. LCrdReturn flit from receiver increments it. No ACK needed — credit return IS the acknowledgement.
Credit flow (REQ channel example): Init: TX_credit = 4 (buffer depth) Send: TX_credit-- (=3) Send: TX_credit-- (=2) Recv LCrdReturn: TX_credit++ (=3) Send: TX_credit-- (=2) If TX_credit==0: STALL until LCrdReturn Per-channel independence: REQ credits ≠ RSP credits ≠ DAT credits ≠ SNP credits DAT channel stall does NOT block REQ channel
Section 07
4×3 Mesh Topology

CMN-700 style 4×3 mesh. Each crosspoint contains a full router. Nodes attach at mesh intersections. Dimension-ordered routing (X first, then Y) guarantees deadlock freedom.
