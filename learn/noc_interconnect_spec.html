01Overview

The Hanuma NoC interconnect is a credit-flow-controlled, wormhole-switched, 2-D mesh Network-on-Chip implementing the AMBA CHI Issue E coherency protocol. It connects eight fully-coherent Request Nodes (RN-F), two Home Nodes (HN-F) acting as directory-based coherency orchestrators, and four Slave Nodes (SN-F) interfacing DDR/HBM memory controllers — all across a 4×4 tile grid of parameterized wormhole routers.

Protocol Layer

AMBA CHI Issue E — four bidirectional channels: REQ, RSP, SNP, DAT. Credit-based flow control; retry via PCrd mechanism.

CHI-E
Transport

Wormhole switching; 4 Virtual Channels per port enforcing deadlock-free VC class separation (REQ/SNP → RSP → DAT precedence).

Wormhole4 VCs
Arbitration

Default round-robin per output port via arb_unit. Strict-priority and weighted-RR compile-time selectable via POLICY parameter.

06Virtual Channel Class Map

Four VCs per port enforce deadlock-free routing. Response-class VCs are never blocked by request-class VCs. This implements the standard CHI protocol-level deadlock avoidance requirement.

VCClassCHI Channel(s)PriorityRationale
VC0RequestREQ, SNPBaseInitiator requests and snoops; can block on VC1/VC2 but not vice-versa
VC1ResponseRSPElevatedCompAck, SnpResp — must never be blocked by outstanding REQ-class flits
VC2DataDATElevatedCompData, SnpRespData, WriteData — large payload, class-separated from control
VC3High-Priority / RetryRSP (PCrd, RetryAck)HighestRetry protocol flits; must drain even under backpressure to avoid livelock

Deadlock prevention rule: virtual_channel_mgr enforces that an allocation from VC0 (request class) will never stall waiting on a VC1/VC2 (response/data class) buffer in the same direction. Response-class output VC is always guaranteed minimum one free slot.

10Protocol Detection

Detected Protocol: AMBA CHI Issue E (Custom Mesh Switch Fabric)

The interconnect implements a custom 2-D mesh switch fabric that transports AMBA CHI Issue E flits. It is not a raw AXI or AHB bus — CHI flits are packetized at injection ports and depacketized at ejection ports. Evidence from the source:

  • chi_pkg.sv imports: chi_channel_e, chi_cache_state_e, CHI_ADDR_WIDTH, CHI_DATA_WIDTH, CHI_NODE_ID_WIDTH
  • chi_packetizer.sv wraps CHI channel structs into noc_flit_ctrl_t with channel-type field [2:0] and QoS [8:5]
  • chi_link_layer.sv implements CHI-E link activation handshake: TXLINKACTIVEREQ/ACK
  • chi_transport_layer.sv manages TXNID pool, PCrd budget, and retry flow — CHI-E mandatory features
  • chi_protocol_layer.sv FSM handles MOESI-like cache state transitions: Invalid→Unique→Shared→Invalid
  • chi_hn.sv parameter comment: "CHI Issue E coherency" + directory with 1024 entries, 4-way set-associative
  • No AXI/AHB signal naming (AWID, HADDR, HSEL) found anywhere in the RTL

11Arbitration Logic

The SA stage instantiates one arb_unit per output port (5 total per router). The policy is a compile-time parameter ARB_POLICY of type noc_arb_policy_e.

PolicyEnumMechanismFairnessUse-Case
Round-Robin ARB_ROUND_ROBIN Rotating priority pointer rr_ptr; request vector doubled and shifted; fixed-priority encoder on rotated vector; pointer advances to (granted+1)%N on each grant Max-min fair among all requesters over time Default for all SA ports in router
Strict Priority ARB_STRICT_PRIO First-set-bit encoding — lowest index always wins; no state None — can starve higher-index ports QoS-critical or latency-sensitive streams
Weighted RR ARB_WRR Implemented in qos_manager; WRR across 4 traffic classes before feeding SA Proportional to weight — configurable per class QoS differentiation across REQ/RSP/SNP/DAT

Round-Robin Implementation Detail

The arb_unit implementation in arb_unit.sv:

  1. Double the request vector: req_rot = {req, req} >> rr_ptr
  2. First-set-bit encode on the rotated vector → grant_rot
  3. Un-rotate: grant[(i + rr_ptr) % N] = grant_rot[i]
  4. On posedge: advance rr_ptr = (granted_idx + 1) % N

Assertions: $onehot0(grant) and (grant & ~req) == 0 verified every cycle.

QoS Manager Integration

qos_manager.sv sits upstream of the SA stage and performs WRR across 4 traffic classes before presenting requests. Each class has a configurable deficit counter. The manager ensures high-priority (low-latency) classes are serviced with lower deficit accumulation, while bulk/DMA classes receive proportional bandwidth without starvation.

12Flow Control

Credit-Based Flow Control (per-channel, per-direction)

Each CHI link channel maintains an independent credit counter. A flit may only be transmitted when credits are available. Credits are returned by the receiver after consuming a flit from its input buffer.

13Sub-Module Reference

noc_mesh

noc_mesh — noc/noc_mesh.sv
2-D mesh instantiation; statically wires router N/S/E/W ports

Parameterized by ROWS, COLS, FLIT_W. Generates ROWS×COLS router_top instances. N/S/E/W connections are made with generate loops: router at (X,Y) north-out connects to (X,Y+1) south-in, etc. Boundary ports are terminated. Exposes flat inject_flit/valid/ready and eject_flit/valid/ready arrays (one per tile) to noc_top.

router_top

router_top — router/router_top.sv
5-port wormhole router; 5-stage RC→VA→SA→ST→LT pipeline

Instantiates 5× input_port, 5× output_port, one crossbar, 5× arb_unit, 5× route_compute_unit. Flit arrays: ibuf_data[5][4][BUF_DEPTH], xbar signals [5]. SA arbiters receive one-hot request vectors from RC+VA output and produce one-hot grants feeding crossbar select sel[out][in].

crossbar

crossbar — router/crossbar.sv
5×5 non-blocking combinatorial switch fabric

Purely combinatorial (no registers — latency: 0 cycles). Takes in_data[5], in_valid[5], sel[5][5] (one-hot per output port). For each output port, muxes the selected input. Assertion: $onehot0(sel[op]) per output port. Registers are in output_port (LT stage).

arb_unit / round_robin_arb

arb_unit — arbitration/arb_unit.sv  |  round_robin_arb — arbitration/round_robin_arb.sv
Parameterized arbiters used by SA stage and HN-F port arbitration

arb_unit: policy-selectable (RR / strict / default-RR). round_robin_arb: generic N-input standalone RR with mask support — used by HN-F snoop port arbitration and independently by chi_hn for inbound request port selection.

input_port / output_port

input_port — router/input_port.sv
Per-port VC FIFO array + back-pressure control

Contains NUM_VC independent flit_buffer FIFOs. Reports per-VC valid_out and fill_level. Drives ready_out low when any VC is nearly full. The SA stage reads from the head of the winning VC.

output_port — router/output_port.sv
Single-entry skid buffer + credit gating

Single-entry skid buffer decouples crossbar from downstream link timing. Tracks downstream credit count; gates output valid when credit=0. Returns credits upstream on flit accept. Per-VC downstream queuing with arbitration for output link.

flit_buffer / input_buffer / output_buffer

flit_buffer — buffers/flit_buffer.sv
Parameterized synchronous FIFO; gray-code pointers

Depth BUF_DEPTH (default 8), width FLIT_W. Gray-code read/write pointers for metastability-safe occupancy estimation. Almost-full at depth-2 to allow for pipelining latency.

input_buffer — buffers/input_buffer.sv
Multi-VC input buffer; per-VC fill level reporting

Wraps multiple flit_buffer instances, one per VC. Exposes per-VC occupancy count to virtual_channel_mgr and power_mgmt. Supports priority drain of VC3 (retry class).

output_buffer — buffers/output_buffer.sv
Single-entry skid buffer on router output path

Absorbs one-cycle stall from downstream back-pressure. Prevents crossbar stall propagation. Acts as elastic register: full → stall crossbar; empty → pass through.

chi_packetizer / chi_depacketizer

chi_packetizer — packetizer/chi_packetizer.sv
CHI typed flit structs → noc_flit_ctrl_t wide-bus format

Accepts separate REQ/RSP/SNP/DAT channel valid+flit inputs. Serializes into a single noc_flit_ctrl_t header (channel[2:0], VC[1:0], QoS[3:0]) concatenated with flit data. Priority encoder selects channel when multiple are valid. Output: single pkt_out / pkt_valid / pkt_ready stream to mesh inject port.

chi_depacketizer — depacketizer/chi_depacketizer.sv
noc_flit_ctrl_t → typed CHI channel steering

Decodes channel[2:0] from flit header and steers to correct REQ/RSP/SNP/DAT output. Generates decode_error if channel field is invalid. Asserts per-channel valid and passes flit payload. Single-cycle combinatorial decode.

chi_hn / chi_rn / chi_sn

chi_hn — chi/chi_hn.sv
Home Node (HN-F): directory coherency orchestrator

Receives REQ from N RN ports. Performs directory lookup (1024 entries, 4-way, DIR_LOOKUP_LATENCY cycles). Issues snoops to relevant RNs; waits for SnpResp. Forwards data from LLC (hit, LLC_HIT_LATENCY cycles) or fetches from SN. Manages up to 64 outstanding TXNID slots and 32 in-flight snoops. Connects to LLC slice via read/write valid-ready handshake.

chi_rn — chi/chi_rn.sv
Request Node (RN-F/RN-I): requester + snoop responder

Issues READ/WRITE/ATOMIC REQ transactions. Tracks outstanding TXNIDs. Handles incoming SNP from HN: computes snoop response including cache state (UD, UC, SC, I) and optionally data. Implements CompAck sequencing. Contains retry flow control: receives RetryAck + PCrdGrant, holds transaction until credit allocated.

chi_sn — chi/chi_sn.sv
Slave Node (SN-F): CHI ↔ DDR/HBM bridge

Receives ReadNoSnp / WriteNoSnp from HN. Bridges to memory controller (DDR/HBM) via internal protocol. Returns CompData or Comp+DBIDResp. No coherency state — simple request/response. Handles data-less and data-bearing write variants.

chi_link_layer / chi_link_training / credit_manager

Link Layer Stack — link/

virtual_channel_mgr

virtual_channel_mgr — flow_control/virtual_channel_mgr.sv
VC allocation, deallocation, deadlock-free class enforcement

Takes allocation requests from RC/VA stages. Enforces: REQ+SNP → VC0, RSP → VC1, DAT → VC2, Retry → VC3. Tracks buffer occupancy per port/VC. Denies VC0 allocation if VC0 buffers are full while VC1/VC2 are not (prevents request from starving response). Asserts deadlock_suspected if occupancy circular wait patterns are detected.

qos_manager

qos_manager — qos/qos_manager.sv
Weighted Round-Robin across 4 traffic classes with deficit counters

Traffic classes mapped to QoS field [3:0] from CHI flit header. WRR with configurable weights per class (register-programmable). Deficit counter accumulates unused bandwidth and applies it in subsequent rounds — prevents starvation. Feeds class-prioritized requests to SA arbiter stage.

chi_transport_layer / chi_protocol_layer

chi_transport_layer — transport/chi_transport_layer.sv
TXNID pool, PCrd budget, retry flow, timeout watchdog

Manages pool of TXNID slots (parameterized). Allocates a TXNID per new transaction; frees on completion. Tracks PCrd budget per transaction type; blocks new REQ if credit exhausted. Retry FSM: hold transaction state on RetryAck, re-issue after PCrdGrant. Per-TXNID timeout timer — reports expired transactions to timeout_mgr.

chi_protocol_layer — protocol/chi_protocol_layer.sv
CHI-E coherency FSM (RN-F); MOESI-like cache state transitions

State machine: Invalid, UniqueClean, UniqueDirty, SharedClean, SharedDirty per cache line. Handles incoming snoops: determines response opcode (SnpResp vs SnpRespData) and data passing. Manages CompAck sequencing: waits for Comp before sending CompAck. Issues cache-state-driven REQ opcodes (ReadUnique for store-hit-shared, etc.).

route_compute_unit / routing_table

route_compute_unit — routing/route_compute_unit.sv
XY-deterministic routing; purely combinatorial

Extracts TgtNodeID from flit header to get destination (X,Y). Algorithm: if dst_x != MY_X → route East or West; else if dst_y != MY_Y → route North or South; else → Local. Zero-cycle latency (combinatorial). No routing table — static XY guarantees deadlock freedom for the mesh.

routing_table — routing/routing_table.sv
Programmable table-based alternate routing (irregular topologies)

Alternative to XY routing; activated by compile-time parameter. Register-programmable route entries indexed by TgtNodeID. Supports irregular or optimized routes for non-uniform traffic patterns. Higher area cost but flexible for future topology changes.

async_fifo / cdc_sync

async_fifo — clock_crossing/async_fifo.sv
Full-width flit CDC; gray-code pointer synchronization

Used when a CHI node tile operates at a different clock from the NoC mesh clock. Gray-code write/read pointers crossed via cdc_sync. FIFO depth must satisfy: depth ≥ 2×(max_synchronizer_latency + pipeline_depth) to avoid underrun under back-pressure.

cdc_sync — clock_crossing/cdc_sync.sv
2-FF or 3-FF single-bit synchronizer

Standard 2-stage (or 3-stage for high-frequency) flip-flop synchronizer for single-bit control signals crossing clock domains: link_active, credit_return, reset_n crossing. MTBF-compliant at target frequency. Never used for multi-bit data paths — those use async_fifo.

perf_monitor / timeout_mgr / error_handler

perf_monitor — monitoring/perf_monitor.sv
8 configurable event counters per monitor instance

Counts: flit_injected, flit_ejected, arb_stall_cycles, vc_full_cycles, credit_stall_cycles, timeout_events, retry_events, error_events. 64-bit saturating counters. Register-readable via APB/config interface. One instance per router or per-cluster.

timeout_mgr — monitoring/timeout_mgr.sv
Centralized per-slot transaction timeout watchdog

Tracks all outstanding TXNID slots. Per-slot countdown timer; configurable timeout value. On expiry: asserts timeout_valid, encodes slot ID and node_id, drives error to error_handler. Prevents livelock from lost flits or dead nodes.

error_handler — monitoring/error_handler.sv
Priority-encoded error aggregation, latch, IRQ

Inputs: 8 error sources (configurable). Priority encoder selects highest-priority active error. Latches first error (sticky until cleared). Drives: err_valid, err_code (noc_err_code_e), err_capture_id. Separate IRQ outputs: irq_fatal, irq_error, irq_warning. Software clear via err_clear vector.

power_mgmt

power_mgmt — power_management/power_mgmt.sv
Per-tile clock-gating enable based on buffer occupancy and idle threshold

Monitors buf_count from virtual_channel_mgr and flit injection activity. If a tile has zero buffer occupancy and no injection for N consecutive cycles (programmable idle threshold), asserts clock-gate enable for that tile's router_top. Wakes tile on any incoming flit or injection request. Reduces dynamic power in sparse-traffic scenarios without architectural visibility.
