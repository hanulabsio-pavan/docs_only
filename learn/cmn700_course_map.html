01

The Mesh Fabric & Crosspoints built · ready

The transport layer everything else rides on: XP routers, ports, coordinates, links, routing.
PHASE A
~45 min
▸
Goal

Understand the physical substrate of CMN-700 — how a 2-D mesh of crosspoints moves CHI flits between components — before any coherency logic is layered on.

You'll be able to
  • Draw an XP (MXP) and label its mesh ports and device ports.
  • Explain the (X,Y) coordinate system and how node IDs are composed.
  • Describe credited, per-channel links and the double-mesh-channel option.
  • Trace how a flit is routed deterministically from one XP to another.
Topics
  • Mesh as transport layer; rectangular grid up to 12×12 = 144 XPs.
  • Crosspoint anatomy: 4 mesh ports (N/S/E/W) + device ports; internal per-channel switching.
  • Coordinates (XID/YID), node-ID composition (XP coords + port + device).
  • Links & flits; the four channels as independent networks; channel width & double mesh channel; bandwidth math.
  • Deterministic dimension-ordered routing & why it's deadlock-free.
  • Device attachment limits (3 per XP, 4 on edge) and the CAL.
Key terms
XP / MXPmesh portdevice portXID / YIDnode IDflitcredited linkdouble mesh channeldimension-order routingCAL
Interview angle"Sketch the CMN-700 mesh and walk a packet from a CPU to a memory controller." This lesson is what lets you draw it confidently.
Builds on: your NoC fundamentals. Prereq for: everything.

~50 min

Goal

  • Subordinate nodes: SN-F (memory controller), SBSX (CHI→ACE5-Lite bridge).
  • Glue: CAL aggregation, ADB/CDB domain bridges, CFG node, clock/power-domain crossing.

Home Node Internals — SLC + Snoop Filter planned

PHASE B

▸
