Leaf Primitives

Four small modules in nearly every router and link block: a synchronous flit FIFO, a credit counter, a 2-flop synchronizer, and an asynchronous FIFO. Master these and the bigger modules collapse into "FIFO + arbiter + state machine" patterns.

2credit_manager — counting permits to send

Each CHI channel uses credit-based flow control. Sender starts with INIT_CREDITS tokens, spends one per flit, gets one back per LCrdV. Watch the {flit_sent, lcrd_return} = 2'b11 net-zero case.

3cdc_sync — 2-flop synchronizer

The smallest module in the codebase, and the most important. Two cascaded flops in the destination domain give a metastable signal time to resolve. Protects every cross-domain control signal in the NoC.

Why 2 flops? The first captures the asynchronous signal — may be metastable for some τ_resolve. The second samples after one full clk_dst period, by which time the first has almost certainly settled. MTBF in modern processes: years to millennia.

4async_fifo — Gray-code pointer FIFO

To pass a multi-bit value between two clock domains, you can't use cdc_sync on each bit — bits could synchronize on different cycles. The answer: store data in shared memory, synchronize only the Gray-coded pointers. Gray code guarantees one bit changes per increment.

Binary vs Gray, depth-8

Watch which bits change as you advance. Binary often flips many bits together; Gray always flips exactly one.

6Check yourself

Q1. Why does flit_buffer use a pointer one bit wider than $clog2(DEPTH)?
The extra MSB is a wrap bit. Without it, wr_ptr == rd_ptr is ambiguous — could mean empty or full. With the wrap bit, full = (MSBs differ) && (indexes equal); empty = full pointer match. No counter needed.
Q2. In credit_manager, what would go wrong if the 2'b11 case decremented instead of doing nothing?
You'd leak credits. Each cycle where both events happen would lose one credit forever — eventually the sender runs out. The 2'b11 net-zero case keeps the pool stable at sustained throughput.
Q3. Why is a single cdc_sync not enough for a multi-bit bus?
Each bit resolves metastability independently. If the bus changes while sampled, some bits may catch the new value and others the old — a transient corrupted word. Use async_fifo: only Gray-coded pointers cross domains.
Q4. What's the (* ASYNC_REG = "TRUE" *) attribute doing in cdc_sync.sv?
Tells synthesis: don't optimize, retime, or clock-gate these flops; place them physically adjacent. Without it, synth might combine sync_q[0] with sync_q[1], breaking the metastability margin.
