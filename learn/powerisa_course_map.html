Quick-reference glossary

Where to go for primary sources

Specifications

  • Power ISA v3.1 (2020) — the POWER10 baseline, adds prefixed instructions and MMA.
  • Power ISA v3.0B / 3.0C — the version most open reference cores target.
  • v3.1C (2024) — the current errata-corrected release from the OpenPOWER Foundation.
  • Published by the Instruction Set Architecture Technical Working Group, with a public RFC process for changes.

Open implementations to read

  • Microwatt — a small, readable Power ISA core in VHDL; fits in a modest FPGA.
  • A2I / A2O — IBM’s opened server-class softcores.
  • Libre-SOC — an open hybrid CPU/GPU/VPU effort built on Power.
  • Chiselwatt — the same idea in Chisel, useful for comparison.

Toolchain

  • GCC / LLVM — both have mature Power back-ends; -mcpu=power9 / power10.
  • binutils — objdump -d is the fastest way to see real encodings.
  • QEMU — full-system ppc64 / ppc64le emulation for experimenting.
  • gem5 — cycle-level modelling if you care about microarchitecture.

Where Power actually runs

  • IBM Power Systems — POWER9 / POWER10 under AIX, IBM i and Linux.
  • Summit (Oak Ridge) and Sierra (Livermore) — POWER9 + NVIDIA Volta supercomputers.
  • ppc64le Linux — the little-endian ELFv2 platform most modern software targets.
  • Embedded — NXP e-series in automotive and networking; plus a long console legacy.
