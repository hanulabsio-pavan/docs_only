// Example Transactions //
AXI — Read Transaction (Master→Slave)
Master drives AR: ADDR=0x1000, LEN=4, SIZE=4B, ID=1
Slave asserts ARREADY → handshake complete
Slave returns 4 beats on R: DATA[0..3], RLAST on beat 4
Master asserts RREADY each beat → transaction done
AR: ADDR=0x1000 LEN=4 ID=1 ──▶ Slave
Slave ──▶ R: D0 D1 D2 D3·RLAST
No routing. No NodeID. One layer.
CHI — ReadShared Transaction
PROTO CPU0 issues ReadShared to HomeNode, Addr=0x1000, TxnID=42
NET Packet: SrcID=CPU0, TgtID=HN5 → routed hop-by-hop via mesh
LINK Each hop: sender checks credit → sends flit → receiver returns credit
PROTO HomeNode sends SnpShared to CPU1 (has cached copy)
PROTO CPU1 responds SnpResp_SC + data → HN forwards to CPU0
CPU0──[NET]──▶HN5: ReadShared(0x1000)
HN5──[NET]──▶CPU1: SnpShared(0x1000)
CPU1──▶HN5──▶CPU0: Data+SnpResp_SC
3 layers active simultaneously.
