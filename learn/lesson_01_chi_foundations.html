CHI Foundations & the Link Interface

Before reading any router or node logic, you need to know what a flit is, what the four CHI channels do, and how two nodes talk over a link. Everything else in rtl/interconnect/ builds on these three concepts.

1The big picture

CHI lets CPU clusters, memory controllers, and IO agents share data coherently. Every agent is one of three kinds — RN, HN, SN — and they all communicate over four channels. Click any channel to highlight just its path.

2The four channels

Each CHI channel carries a different kind of message and has its own flit structure, opcode set, and virtual-channel assignment. Widths are from chi_pkg.sv.

CHI_CH_REQ  ·  VC0
REQ — Requests

Read, write, atomic, and DVM transactions issued by a Request Node toward a Home Node. The channel that starts every transaction.

Flit width: 88 bits Direction: RN → HN Opcodes: ~35
CHI_CH_RSP  ·  VC1
RSP — Responses

Completions, acknowledgements, retries, credit grants. No data — just protocol-level status.

Flit width: 46 bits Direction: bidirectional Opcodes: ~20
CHI_CH_SNP  ·  VC0
SNP — Snoops

Coherency probes from a Home Node to Request Nodes. Asks an RN to invalidate or share its cached copy of a line.

Flit width: 84 bits Direction: HN → RN Opcodes: ~20
CHI_CH_DAT  ·  VC2
DAT — Data

Cache-line payload — read returns, writeback data, snoop responses with data. The widest channel by far.

Flit width: 368 bits Direction: bidirectional Opcodes: ~12

4The three node families

Every CHI participant is one of these. The role determines which channels it drives and receives.

RN-F · RN-I · RN-D

Request Node

The initiator. CPUs, DMA engines, accelerators.

  • Sends: REQ, RSP, DAT
  • Receives: SNP, RSP, DAT
  • RTL: chi_rn.sv
  • F = Fully Coherent (with cache)
  • I = IO Coherent (no cache)
HN-F · HN-I

Home Node

The arbiter of coherency. Owns the directory and the last-level cache.

  • Sends: RSP, SNP, DAT
  • Receives: REQ, RSP, DAT
  • RTL: chi_hn.sv
  • F = LLC + Directory
  • I = MMIO regions (no caching)
SN-F · SN-I

Slave Node

The endpoint. Memory controllers and IO peripherals.

  • Sends: RSP, DAT
  • Receives: REQ, DAT
  • RTL: chi_sn.sv
  • F = DDR / fully coherent memory
  • I = peripherals

5The link-layer handshake

Every channel uses the same three signals: pend announces the sender's intent, valid carries the flit, lcrdv returns a credit. Press play to step through.

7Check yourself

Q1. A CPU sends a ReadShared and a memory controller eventually replies with CompData. Which channels and VCs?
ReadShared is REQ on VC0. CompData is DAT on VC2. Mapping in noc_pkg.sv :: channel_to_vc().
Q2. Why is REQ 88 bits but DAT 368 bits? What does that imply for router buffer sizing?
REQ carries protocol metadata; DAT carries a 256-bit cache line plus byte-enables and tags. Router buffers must size to the widest flit (NOC_FLIT_WIDTH = CHI_DAT_FLIT_WIDTH), so every per-VC FIFO is 368×8 regardless of which channel uses it.
Q3. Why does txreqflitpend rise one cycle before txreqflitv?
Early hint that lets the receiver pre-decode its buffer write enable in time. Without pend, the receiver would have to combinationally gate every incoming flit — a timing hazard at 1 GHz.
Q4. Where is the modport for the requester side of a CHI link?
rtl/interfaces/chi_link_if.sv:106. Mirror is completer on line 125; monitor (line 144) is read-only for assertions.
