REQ
Request Channel
Requester Node (RN) → Home Node (HN) · Initiates all transactions
20 fields
Field Bits Category Description
QoS4QoSQuality of Service priority — 0 (lowest) to 15 (highest). Controls arbitration ordering at interconnect.
TgtID11RoutingTarget Node ID. Physical node ID of the Home Node this request is addressed to. Used by Network Layer for routing.
SrcID11RoutingSource Node ID. Identifies the Requester Node sending this flit. Used for routing return traffic.
TxnID8RoutingTransaction ID. Unique per source node. Used to correlate all flits belonging to the same transaction.
ReturnNID11RoutingReturn Node ID. The node ID to which data must be forwarded (used in DMT/DCT snoop forwarding flows).
ReturnTxnID8RoutingReturn Transaction ID. The TxnID to use in the forwarded data response to ReturnNID.
StashNID11RoutingStash Node ID. Identifies the target node for Stash transactions (prefetch to specific cache).
StashNIDValid1ControlIndicates StashNID field is valid. If 0, StashNID is not used.
StashLPID5RoutingStash Logical Processor ID. Target LP within the stash node for prefetch hinting.
StashLPIDValid1ControlIndicates StashLPID is valid.
Opcode6ControlRequest opcode. Defines the transaction type: ReadShared, ReadUnique, WriteBack, WriteClean, MakeUnique, CMO, AtomicStore, etc.
Addr44–52ControlPhysical address of the target cache line. Width is implementation-defined (44–52 bits).
Size3ControlTransfer size in bytes: 1, 2, 4, 8, 16, 32, or 64 bytes.
NS1MemoryNon-Secure. Indicates if the transaction targets the Non-Secure memory space (TrustZone).
AllowRetry1ControlPermits the target to respond with RetryAck if resources are unavailable, requiring re-issue with a credit.
PCrdType4ControlProtocol Credit Type. Specifies the credit type being consumed when re-issuing after a RetryAck.
ExpCompAck1CoherencyExpect CompAck. Indicates the requester will send a CompAck response to complete the transaction handshake.
MemAttr4MemoryMemory Attributes. Encodes: Allocate, Cacheable, Device, EWA (Early Write Acknowledge) for memory type classification.
SnpAttr1CoherencySnoop Attribute. Indicates whether the cache line is snoopable by other Requester Nodes.
LPID5RoutingLogical Processor ID. Identifies the LP within an RN-F for exclusive access monitoring (load-link/store-conditional).
SnoopMe1CoherencyRequests that the Home Node snoops the requester's own cache as part of this transaction (used with DVM/CMO).
RSVDC4DebugReserved for Customer Use. Passed through the interconnect untouched; available for system-level tracing or tagging.
TraceTag1DebugTrace Tag. Marks this transaction for hardware trace capture — used in performance analysis and debug tooling.
ℹ REQ carries no data payload. Addr + Opcode together fully specify what operation is requested and where.
RSP
Response Channel
Home Node (HN) ↔ Requester Node (RN) · Carries completion, retry, and credit responses
13 fields
Field Bits Category Description
QoS4QoSQuality of Service priority. Mirrors the QoS of the originating request for consistent prioritisation.
TgtID11RoutingTarget Node ID. The node to which this response is directed (usually the original requester).
SrcID11RoutingSource Node ID. Identifies the node sending this response (Home Node or snoopee).
TxnID8RoutingTransaction ID. Matches the TxnID of the originating request to correlate the response.
Opcode4ControlResponse opcode: Comp, CompAck, RetryAck, PCrdGrant, ReadReceipt, SnpResp, DBIDResp, CompDBIDResp, etc.
RespErr2ErrorResponse Error status: OK (00), ExOK (01), DataError (10), NonDataError (11). Signals bus faults or access violations.
Resp3CoherencyCache line state: I (Invalid), SC (Shared Clean), UC (Unique Clean), UD (Unique Dirty), SD (Shared Dirty). MOESI-derived.
FwdState3CoherencyForward State. The cache state being assigned to the requester when data is forwarded from a snoopee (DCT flows).
DataPull1CoherencyIndicates an implied Read request is embedded in this snoop response — triggers data transfer without a separate REQ.
DBID8RoutingData Buffer ID. The ID the requester must use as TxnID when sending write data back to the Home Node.
PCrdType4ControlProtocol Credit Type being granted (in PCrdGrant response). Allows the requester to re-issue a previously retried request.
TraceTag1DebugTrace Tag. Propagated from the originating request for end-to-end transaction tracing.
RSVDC4DebugReserved for Customer Use. Passed through untouched for system-level debug and tagging.
ℹ RSP carries no data payload. It is the lightest channel — used only for handshaking, credit management, and state signalling.
DAT
Data Channel
Home Node ↔ Requester Node ↔ Slave Node · Carries actual cache line data payload
18 fields
Field Bits Category Description
QoS4QoSQuality of Service priority. Preserves the original request's QoS through the data path.
TgtID11RoutingTarget Node ID. The node receiving this data flit.
SrcID11RoutingSource Node ID. The node transmitting this data flit (Home Node, memory controller, or snoopee).
TxnID8RoutingTransaction ID. Correlates this data flit to an outstanding transaction at the target.
HomeNID11RoutingHome Node ID. Tells the requester where to send CompAck once the data is accepted — critical for ordering.
Opcode3ControlData opcode: CompData, SnpRespData, SnpRespDataPtl, CopyBackWrData, NonCopyBackWrData, NCBWrDataCompAck, etc.
RespErr2ErrorError status of this data transfer: OK, ExOK, DataError, NonDataError. Signals ECC/bus errors on the data path.
Resp3CoherencyCache line state associated with this data: I, SC, UC, UD, SD. Tells the receiver what state to install the line in.
FwdState3CoherencyForward State. Cache state being assigned to a third-party requester when data is forwarded by a snoopee (DCT).
DataPull1CoherencyImplied Read request embedded in snoop data response. Eliminates a round-trip REQ for certain coherency flows.
DBID8RoutingData Buffer ID. Used by the receiver to identify which write buffer this data is associated with.
CCID2ControlCritical Chunk ID. Identifies which 16-byte sub-chunk of the cache line is critical — returned first for low-latency access.
DataID2ControlData chunk index. For narrow buses (128-bit), a 64-byte cache line requires multiple flits; DataID identifies which chunk (0–3) this flit carries.
Data128–512DataActual data payload. Width is implementation-defined: 128, 256, or 512 bits. Matches the interconnect data bus width.
BE16–64DataByte Enable. One bit per byte of Data. Indicates which bytes are valid — essential for partial writes and cache line merges.
DataCheck8–32ErrorData integrity check bits (ECC or parity). Allows detection and optionally correction of bit errors in the data payload.
Poison2–8ErrorData Poison flag. One bit per 8 bytes. Marks data as corrupted (propagated ECC error) without raising an immediate fault.
TraceTag1DebugTrace Tag. Enables end-to-end latency measurement from REQ issuance to data receipt.
ℹ DAT is the widest channel. On a 128-bit bus, one 64-byte cache line = 4 flits (DataID 0–3). CCID ensures the critical chunk is returned first to minimise CPU stall.
SNP
Snoop Channel
Home Node (HN) → Snoopee (RN-F) · Requests cache state inspection or invalidation
11 fields
Field Bits Category Description
QoS4QoSQuality of Service priority. Derived from the originating REQ, propagated to prioritise snoop processing.
SrcID11RoutingSource Node ID. Identifies the Home Node issuing the snoop. Used by snoopee to route the SnpResp back.
TxnID8RoutingTransaction ID. The snoopee must echo this TxnID in its SnpResp/SnpRespData to correlate with the HN's tracker.
FwdNID11RoutingForward Node ID. In DCT flows, the snoopee must forward data directly to this node ID instead of returning it to HN.
FwdTxnID8RoutingForward Transaction ID. The TxnID the snoopee must use in the forwarded DAT flit sent to FwdNID.
Opcode5ControlSnoop opcode: SnpShared, SnpUnique, SnpClean, SnpOnce, SnpNotSharedDirty, SnpPreferUnique, SnpUniqueFwd, SnpCleanInvalid, SnpMakeInvalid, SnpDVMOp, etc.
Addr44–52ControlCache-line aligned address of the snoop target. Bits [5:0] are always 0 (64-byte aligned). Width matches REQ channel.
NS1MemoryNon-Secure. Specifies the security attribute of the target address — snoopee must match its cache tag's NS state.
DoNotGoToSD1CoherencyPrevents the snoopee from transitioning the cache line to Shared Dirty state. Ensures clean response only.
RetToSrc1CoherencyReturn to Source. Requests the snoopee to include data in its response even if the line is clean — used for memory updates.
TraceTag1DebugTrace Tag. Propagated from the triggering REQ to enable full transaction tracing across all snoop sub-flows.
ℹ SNP has no TgtID field — the target is implicit from which physical link the flit is dispatched on. The Snoop Filter at HN determines which RN-F nodes to snoop.
