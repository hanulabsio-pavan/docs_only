What you'll build

A small server on a Raspberry Pi at home. It holds Portfolio.xlsx. From anywhere, on mobile data, you ask Claude:

“Update my portfolio prices.”The Pi fetches live NSE prices, writes the LTP column, recalculates every formula and replies with your gain/loss.

Your data

Holdings sheet: 10 NSE stocks with quantity, average price and LTP. Later: assets, debts and net worth.

Your server

Python MCP server with read and write tools. Runs 24×7 as a service.

Your access

Secure HTTPS tunnel. Works over 4G/5G. No router ports opened.

Your safety net

Login required, file locking, snapshots, nightly backups to Drive.

Chapter 1 · ~15 min

Concept & Architecture

MCP in one minute

MCP (Model Context Protocol) lets Claude call functions on your server. Each function is a tool. Claude reads the tool's name and description, then decides when to call it.

  • Client: Claude (phone app, web or desktop).
  • Server: your Python program on the Pi.
  • Transport: Streamable HTTP. One HTTPS endpoint, usually /mcp.

System architecture

Key point: the Pi never opens a port.cloudflared dials out to Cloudflare. Your router stays closed. The Pi still needs home internet; only your phone uses mobile data.

One master copy

Two editable copies (Drive and Pi) will drift. Pick one master:

  • Master: ~/pi-portfolio-mcp/data/Portfolio.xlsx on the Pi.
  • Drive: read-only backups in Finance/backups/.
  • Manual edits: do them through Claude tools, or copy the file off, edit, and put it back while the server is stopped.

Self-Check Quiz

Q1: Your phone is on 5G. Does the Pi also need mobile data?

No. The Pi uses home Wi-Fi/Ethernet. Only the phone uses mobile data. The tunnel connects them through Cloudflare.

Q2: Why does the project need LibreOffice?

  1. To open the file on the phone
  2. Because openpyxl writes formulas but can't calculate them
  3. To fetch stock prices
B. openpyxl only stores formulas. LibreOffice recalculates them and saves the results, so the server can read real totals.

Q3: Where is the master copy of the portfolio?

On the Pi. Google Drive holds dated backups only. One master avoids two copies drifting apart.

Key Takeaways

  • MCP exposes Python functions as tools that Claude can call.
  • Claude's cloud calls your server, so it needs a public HTTPS URL.
  • cloudflared tunnels out; no router ports open.
  • The Pi holds the master file; Drive is backup only.

Workbook design

Your current file stores fixed values from the broker export. They must become formulas. Also, totals move to a new Summary sheet with fixed cells. Then adding or removing a stock never breaks the Dashboard.

Formulas per row

FCurrent value=B3*D3
GOverall G/L=F3-E3
HOverall G/L %=IF(E3=0,0,G3/E3)
IDay's G/L=IF(K3="",0,B3*(D3-K3))
JDay's G/L %=IF(OR(K3="",K3=0),0,(D3-K3)/K3)

"""Excel helpers shared by the setup script and the server."""

def header_row(ws):
    for r in range(1, 20):
        if ws.cell(r, 1).value == "Symbol":
            return r
    raise ValueError("Header row 'Symbol' not found")

def holding_rows(ws):
    """Yield row numbers of holdings (stops at first empty Symbol)."""
    r = header_row(ws) + 1
    while ws.cell(r, 1).value:
        yield r
        r += 1

def apply_row_formulas(ws, r):
    ws[f"E{r}"] = f"=B{r}*C{r}"
    ws[f"F{r}"] = f"=B{r}*D{r}"
    ws[f"G{r}"] = f"=F{r}-E{r}"
    ws[f"H{r}"] = f"=IF(E{r}=0,0,G{r}/E{r})"
    ws[f"I{r}"] = f'=IF(K{r}="",0,B{r}*(D{r}-K{r}))'
    ws[f"J{r}"] = f'=IF(OR(K{r}="",K{r}=0),0,(D{r}-K{r})/K{r})'

def reapply_all(ws):
    """Call after deleting a row: openpyxl does not shift formulas."""
    for r in holding_rows(ws):
        apply_row_formulas(ws, r)
"""Convert values to formulas, add PrevClose and a Summary sheet."""
from openpyxl import load_workbook
from workbook import header_row, apply_row_formulas

PATH = "data/Portfolio.xlsx"
wb = load_workbook(PATH)
ws = wb["Holdings"]
h = header_row(ws)
ws.cell(h, 11, "PrevClose")

r = h + 1
while ws.cell(r, 1).value and ws.cell(r, 1).value != "TOTAL":
    apply_row_formulas(ws, r)
    r += 1
if ws.cell(r, 1).value == "TOTAL":
    ws.delete_rows(r, ws.max_row - r + 1)   # drop TOTAL + footnote

s = wb["Summary"] if "Summary" in wb.sheetnames else wb.create_sheet("Summary")
a, z = h + 1, h + 500                        # room for 500 holdings
rows = [
    ("Total Invested", f"=SUM(Holdings!E{a}:E{z})"),
    ("Current Value",  f"=SUM(Holdings!F{a}:F{z})"),
    ("Overall G/L",    "=B2-B1"),
    ("Overall G/L %",  "=IF(B1=0,0,B3/B1)"),
    ("Day's G/L",      f"=SUM(Holdings!I{a}:I{z})"),
    ("Day's G/L %",    "=IF(B2-B5=0,0,B5/(B2-B5))"),
    ("Last Updated",   None),
]
for i, (label, formula) in enumerate(rows, start=1):
    s.cell(i, 1, label)
    if formula:
        s.cell(i, 2, formula)

wb.save(PATH)
print("Done. Now point Dashboard cells to Summary!B1:B6.")

After running it, open the file once in Excel or LibreOffice. Change the Dashboard's four total cells to =Summary!B1, =Summary!B2, and so on. Rebuild the “best/worst performer” cells with INDEX/MATCH on columns H and J.

Advanced: splits, bonuses and dividends
  • Split or bonus: quantity goes up, average price goes down. Total invested stays the same. Without this fix, G/L looks like a huge loss. Add an update_holding call after each corporate action.
  • Dividends: not part of price G/L. Track them later in a separate Income sheet.
  • Sells: reduce quantity; keep average price. Realised profit belongs in a separate sheet.

Self-Check Quiz

Q1: Why move totals from the Holdings TOTAL row to a Summary sheet?

The TOTAL row moves when stocks are added or removed, and openpyxl does not update references to it. Summary cells never move, and they sum a fixed range of 500 rows.

Q2: What is the PrevClose column for?

  1. Average buy price
  2. Yesterday's closing price, used for Day's G/L
  3. 52-week low
B. Day's G/L = quantity × (LTP − previous close).

Q3: You delete row 5 with openpyxl. What else must you do?

Call reapply_all(ws). Rows below shifted up, but their formulas still point to the old row numbers.

Key Takeaways

  • Use an SSD or good SD card, proper power and cooling.
  • Set timezone to IST and enable the firewall on day one.
  • Replace broker-export values with formulas; add PrevClose.
  • Keep totals in a fixed Summary sheet.

The safe write flow

Every write follows the same path. Step through it below, or press auto-demo.

Price fetcher

"""Fetch last price and previous close from Yahoo (NSE = .NS)."""
import yfinance as yf

ALIASES = {}   # e.g. {"MYSTOCK": "MYSTOCK-BE"} if Yahoo uses another code

def fetch(symbols):
    prices, errors = {}, {}
    for sym in symbols:
        try:
            info = yf.Ticker(f"{ALIASES.get(sym, sym)}.NS").fast_info
            ltp, prev = info.last_price, info.previous_close
            if not ltp or ltp <= 0:
                raise ValueError("no price returned")
            prices[sym] = (round(ltp, 2), round(prev, 2) if prev else None)
        except Exception as e:
            errors[sym] = str(e)       # old LTP stays in the sheet
    return prices, errors

Recalculation

"""Recalculate all formulas with headless LibreOffice."""
import os, subprocess, tempfile
from pathlib import Path

def recalc(xlsx: Path, timeout: int = 120):
    # temp dir on the same disk, so os.replace is atomic
    with tempfile.TemporaryDirectory(dir=xlsx.parent) as tmp:
        subprocess.run(
            ["soffice", "--headless", "--norestore",
             "--convert-to", "xlsx", "--outdir", tmp, str(xlsx)],
            check=True, timeout=timeout, capture_output=True)
        os.replace(Path(tmp) / xlsx.name, xlsx)

The server

"""Pi Portfolio MCP server."""
import os, shutil, logging, datetime as dt
from pathlib import Path
from dotenv import load_dotenv
from filelock import FileLock
from openpyxl import load_workbook
from fastmcp import FastMCP

from workbook import header_row, holding_rows, apply_row_formulas
from prices import fetch
from recalc import recalc

load_dotenv()
XLSX = Path(os.environ["PORTFOLIO_XLSX"])
PREV = XLSX.with_suffix(".prev.xlsx")
LOCK = FileLock(f"{XLSX}.lock", timeout=60)
logging.basicConfig(filename="logs/audit.log", level=logging.INFO,
                    format="%(asctime)s %(message)s")

mcp = FastMCP("pi-portfolio")

def read_summary():
    s = load_workbook(XLSX, data_only=True)["Summary"]
    return {s.cell(r, 1).value: s.cell(r, 2).value for r in range(1, 8)}

def safe_write(change):
    """Snapshot, apply change, recalc, verify. Roll back on any error."""
    with LOCK:
        shutil.copy2(XLSX, PREV)
        try:
            wb = load_workbook(XLSX)
            result = change(wb)
            wb.save(XLSX)
            recalc(XLSX)
            summary = read_summary()
            if not isinstance(summary.get("Current Value"), (int, float)):
                raise RuntimeError("recalc produced no values")
            return result, summary
        except Exception:
            shutil.copy2(PREV, XLSX)        # rollback
            raise

@mcp.tool(annotations={"readOnlyHint": True})
def get_summary() -> dict:
    """Portfolio totals: invested, current value, overall and day's gain/loss."""
    return read_summary()

@mcp.tool(annotations={"readOnlyHint": True})
def get_holdings() -> list[dict]:
    """Every holding with quantity, avg price, LTP and gain/loss."""
    ws = load_workbook(XLSX, data_only=True)["Holdings"]
    keys = [c.value for c in ws[header_row(ws)]]
    return [{k: ws.cell(r, i + 1).value for i, k in enumerate(keys) if k}
            for r in holding_rows(ws)]

@mcp.tool(annotations={"readOnlyHint": False, "idempotentHint": True})
def update_prices() -> dict:
    """Fetch latest NSE prices, update LTP, recalculate, return totals."""
    def change(wb):
        ws = wb["Holdings"]
        rows = {ws.cell(r, 1).value: r for r in holding_rows(ws)}
        prices, errors = fetch(list(rows))
        if not prices:
            raise RuntimeError(f"no prices fetched: {errors}")
        for sym, (ltp, prev) in prices.items():
            ws.cell(rows[sym], 4, ltp)
            if prev:
                ws.cell(rows[sym], 11, prev)
        wb["Summary"]["B7"] = dt.datetime.now().strftime("%d-%b-%Y %H:%M IST")
        return {"updated": len(prices), "failed": errors}
    result, summary = safe_write(change)
    logging.info("update_prices %s", result)
    return {**result, "summary": summary}

@mcp.tool(annotations={"readOnlyHint": False, "destructiveHint": False})
def add_holding(symbol: str, quantity: float, avg_price: float) -> dict:
    """Add a new NSE stock, e.g. INFY. Use update_holding for existing ones."""
    symbol = symbol.strip().upper()
    def change(wb):
        ws = wb["Holdings"]
        rows = list(holding_rows(ws))
        if any(ws.cell(r, 1).value == symbol for r in rows):
            raise ValueError(f"{symbol} already exists")
        r = (rows[-1] if rows else header_row(ws)) + 1
        ws.cell(r, 1, symbol); ws.cell(r, 2, quantity); ws.cell(r, 3, avg_price)
        apply_row_formulas(ws, r)
        return {"added": symbol}
    result, summary = safe_write(change)
    logging.info("add_holding %s qty=%s avg=%s", symbol, quantity, avg_price)
    return {**result, "summary": summary}

if __name__ == "__main__":
    mcp.run(transport="http", host="127.0.0.1", port=8000)

update_holding and remove_holding follow the same safe_write pattern. For remove, call reapply_all(ws) after ws.delete_rows(r).

Advanced: market hours, delays and rate limits
  • NSE trades 9:15–15:30 IST on weekdays. Outside those hours you get the last close. That is fine; the “Last Updated” cell tells you when.
  • yfinance prices may be delayed. Don't use them for trading decisions.
  • Yahoo may throttle heavy use. Update on request or a few times a day, not every minute.
  • For real-time data, a broker API (for example Upstox or Zerodha Kite Connect) can replace prices.py later. Only that one file changes.

Self-Check Quiz

Q1: Yahoo returns no price for one symbol. What happens?

The old LTP stays. The symbol appears under failed in the reply, so Claude can tell you. Only if all symbols fail does the update abort.

Q2: Why take a .prev.xlsx snapshot before every write?

  1. Faster reads
  2. To roll back if save or recalc fails midway
  3. To keep Drive in sync
B. A crash during save or recalc could leave a broken file. The snapshot restores the last good state.

Q3: Why bind the server to 127.0.0.1 and not 0.0.0.0?

So only local programs (cloudflared) can reach it. Other devices on your Wi-Fi can't bypass the tunnel and its login.

Key Takeaways

  • Tools are plain Python functions; docstrings tell Claude when to use them.
  • All writes go through one safe_write: lock, snapshot, change, recalc, verify, rollback.
  • Failed symbols keep old prices and are reported.
  • Test with MCP Inspector before going remote.

Chapter 4 · ~15 min

Remote Access & Security

Why not port forwarding?

  • Many Indian ISPs use CGNAT. Your router has no public IP, so forwarding won't work.
  • An open port gets scanned within hours.
  • You'd need to manage certificates yourself.

Tunnels solve all three. Compare the two options:

RecommendationStart with Tailscale in phase 2 (private, 5-minute setup) for testing. Move to Cloudflare Tunnel + OAuth in phase 3 for the phone app.

Add OAuth login

FastMCP includes OAuth providers. With GitHub: create an OAuth app, set its callback to your server URL, then:

from fastmcp.server.auth.providers.github import GitHubProvider
from fastmcp.server.dependencies import get_access_token

auth = GitHubProvider(
    client_id=os.environ["GITHUB_CLIENT_ID"],
    client_secret=os.environ["GITHUB_CLIENT_SECRET"],
    base_url="https://mcp.yourdomain.com",
)
mcp = FastMCP("pi-portfolio", auth=auth)

OWNER = os.environ["ALLOWED_GITHUB_USER"]

def require_owner():
    """Call at the start of every tool: only your account gets in."""
    token = get_access_token()
    if not token or token.claims.get("login") != OWNER:
        raise PermissionError("not allowed")
Check the docs for your versionFastMCP's auth API changes between releases. Confirm the provider name, callback path and claim names in the FastMCP docs before deploying. Test that a second GitHub account is rejected.

Self-Check Quiz

Q1: Why can't the Claude phone app use your Pi's Tailscale IP?

For custom connectors, Claude's cloud servers make the call, not your phone. Those servers aren't on your tailnet, so the 100.x address is unreachable.

Q2: Your phone is stolen. What's the fastest way to block access?

  1. Unplug the router
  2. Revoke the GitHub OAuth grant (or stop cloudflared)
  3. Delete the Excel file
B. Revoke the app's authorization in GitHub settings and sign out of Claude. For an instant stop, run systemctl stop cloudflared.

Key Takeaways

  • CGNAT makes port forwarding unreliable; tunnels avoid it.
  • Claude app → needs public HTTPS (Cloudflare) + OAuth.
  • Tailscale is ideal for private testing and desktop clients.
  • systemd keeps the server running; the checklist keeps it safe.

Chapter 5 · ~15 min

Operations, Testing & Roadmap

Backups

Three layers protect the file:

  1. Per write: Portfolio.prev.xlsx (Chapter 3).
  2. Nightly: dated copy on the Pi, kept 30 days.
  3. Off-site: the same copy uploaded to Google Drive with rclone.
#!/usr/bin/env bash
# Nightly snapshot: keep 30 days locally, copy to Google Drive.
set -euo pipefail
cd /home/pi/pi-portfolio-mcp
ts=$(date +%F)

# flock waits for any running write (same lock file as the server)
flock data/Portfolio.xlsx.lock cp data/Portfolio.xlsx "backups/Portfolio-$ts.xlsx"
find backups -name 'Portfolio-*.xlsx' -mtime +30 -delete
rclone copy "backups/Portfolio-$ts.xlsx" gdrive:Finance/backups/
# Every night at 23:30 IST
30 23 * * * /home/pi/pi-portfolio-mcp/backup.sh >> /home/pi/pi-portfolio-mcp/logs/backup.log 2>&1
Do a restore drillA backup you never restored is a guess. Once a month: stop the service, copy a backup over the master, start the service, call get_summary.

Testing

Test the Excel logic without the network. Mock prices; never hit Yahoo in tests.

from openpyxl import Workbook
from workbook import apply_row_formulas, holding_rows, reapply_all

def sheet():
    ws = Workbook().active
    ws.title = "Holdings"
    ws.append(["Symbol", "Quantity", "Avg. Price", "LTP"])
    ws.append(["AAA", 10, 100, 110])
    ws.append(["BBB", 5, 200, 190])
    return ws

def test_rows_found():
    assert list(holding_rows(sheet())) == [2, 3]

def test_formulas_written():
    ws = sheet()
    apply_row_formulas(ws, 2)
    assert ws["E2"].value == "=B2*C2"
    assert ws["G2"].value == "=F2-E2"

def test_delete_then_reapply():
    ws = sheet()
    reapply_all(ws)
    ws.delete_rows(2)
    reapply_all(ws)
    assert ws["A2"].value == "BBB"
    assert ws["E2"].value == "=B2*C2"   # not =B3*C3

Self-Check Quiz

Q1: Why does backup.sh use flock on the same lock file?

So the copy waits if a price update is writing at that moment. Without it, you could back up a half-written file.

Q2: Phase 3 is “done” when…?

  1. cloudflared is installed
  2. The Claude app updates prices over mobile data, and another account is refused
  3. The domain is bought
B. “Done” means an outcome you can test end to end, including the negative case.

Q3: Why mock prices in unit tests?

Real prices change and the network can fail. Tests must give the same result every run.

Key Takeaways

  • Three backup layers: per-write snapshot, nightly local, off-site Drive.
  • Test restores, not just backups.
  • Unit-test the Excel logic with mocked prices.
  • Every roadmap phase has a testable “done when”.
